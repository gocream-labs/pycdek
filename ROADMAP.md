# Roadmap

Цель актуализации — сначала сделать проверяемой текущую реализацию, затем
выпустить совместимую 2.0.0 и только после этого подготовить 3.0.0 с
ломающими изменениями.

Модуль `gocream_pycdek/` на этом этапе не меняем.

- [x] Перенести dev-зависимости в `[dependency-groups]`.

- [x] Добавить `pre-commit`/`prek` и `commit-msg`-хук.
