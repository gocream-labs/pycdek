## Parameter Descriptions

Описания параметров методов API v2 сверены 24 сентября 2026 года с [официальной OpenAPI-спецификацией СДЭК](https://gateway.cdek.ru/api-cdek-docs/web/docs/merged?sectionId=api_v2_integration), используемой [порталом документации](https://apidoc.cdek.ru/). Значения по умолчанию на стороне API отмечены отдельно от значений аргументов клиента. `origin_response`, `raise_errors`, HTTP-настройки и генераторы `get_all_*` относятся к интерфейсу библиотеки.

При сверке обнаружены расхождения. Устаревшие и не подтверждённые спецификацией параметры помечены
`DeprecationWarning` при вызове и разделом `Deprecated` в докстринге:

- Спецификация списка регионов не перечисляет `region_code` и `kladr_region_code` вообще - это не поля,
  помеченные устаревшими, а параметры, которых в контракте API никогда не было. Список городов не
  перечисляет `kladr_region_code` по той же причине. Все три оставлены в клиенте для обратной
  совместимости и будут удалены в 3.0.0.
- `fias_region_guid` (`get_regions`, `get_cities`) и `kladr_code` внутри адреса забора
  (`registrate_intakes.from_location`) в спецификации присутствуют, но помечены устаревшими:
  значения могут быть неактуальны. Для `from_location` это флаг из документации, а не клиента -
  рантайм-предупреждения на уровне отдельных полей вложенного словаря клиент не выдаёт.
- Поле `print` при регистрации заказа принимает `WAYBILL` и `BARCODE` (регистр важен). Аргумент клиента
  называется `request_print`, а не `print`, - имя `print` в Python занято встроенной функцией, и приём её
  как ключевого параметра сделал бы `print(...)` недоступным внутри метода. Прежнее описание аргумента
  ошибочно показывало значения в нижнем регистре (`barcode`, `waybill`); это исправлено, само поведение
  клиента (значение уходит как есть, без изменения регистра) не менялось.
- `get_shipping_cost` относится к legacy API и отсутствует в актуальной спецификации v2. Метод уже
  оформлен как deprecated (`DeprecationWarning` в рантайме, раздел `Deprecated` в докстринге,
  запланированное удаление в 3.0.0 - см. [roadmap](../roadmap.md)). Его параметры описаны по
  существующему интерфейсу, без подмены контрактом нового калькулятора.
